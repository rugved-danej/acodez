<h1 align="center">AcodeZ - Public Community</h1>

Welcome to the public community hub for **[AcodeZ](https://www.npmjs.com/package/@rvrugved/acodez)**, the ultimate zero-config CLI framework for building Acode plugins in TypeScript and JavaScript.

Since the core source code is kept in a private repository, this public repository serves as the official place for developers to interact with the project!

## 🤝 How you can contribute:

### 🐛 Found a Bug?
If you've encountered a crash, an error, or something isn't working as expected when using `acodez`, please let us know!
👉 **[Submit a Bug Report](https://github.com/rugved-danej/acodez/issues/new?assignees=&labels=bug&projects=&template=bug_report.yml)**

### 💡 Have a Feature Request?
Got a brilliant idea to make AcodeZ even better? We'd love to hear it!
👉 **[Submit a Feature Request](https://github.com/rugved-danej/acodez/issues/new?assignees=&labels=enhancement&projects=&template=feature_request.yml)**

### 💬 Need Help or Want to Discuss?
If you're stuck, have a question about how to build plugins, or just want to chat with other developers using AcodeZ, head over to the Discussions tab.
👉 **[Join the Discussions](https://github.com/rugved-danej/acodez/discussions)**

---

### 📦 Installation
If you haven't installed the CLI yet, you can initialize a new plugin instantly by running:
```sh
npx @rvrugved/acodez init my-plugin
```
